# Soft Shader Auto Edition

A lightweight Minecraft Bedrock resource pack focused on softer biome colors.

## Features
- Soft sage-green grass tint
- Softer foliage tint
- Soft blue/teal water tint
- No commands, cheats, behavior pack, or Vibrant Visuals required
- GitHub Actions builds the installable `.mcpack`

## Build
Open **Actions → Build Soft Shader MCpack → Run workflow**. Download the `Soft-Shader-Auto.mcpack` artifact from the completed run.

## Install
1. Download the `.mcpack` file.
2. Open it with Minecraft.
3. Activate it under the world's Resource Packs.

## Important limitation
This is a texture-based visual resource pack, not a GPU shader. Standard Bedrock resource packs without Vibrant Visuals cannot add real-time dynamic lighting, shadows, reflections, or bloom. Results may vary by biome and game version.

Target: Minecraft Bedrock 1.26.x.
